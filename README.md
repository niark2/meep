# meep

Un clicker. Une nuit. Un crabe.

Ouvre `index.html` dans un navigateur, c'est tout. Aucune dépendance, aucun build.

- clique sur le crabe
- les paliers se débloquent dans la boutique à droite
- les objectifs à gauche donnent des bonus quand tu les réclames
- trois codes sont cachés dans le bouton 🔑
- le cadeau se mérite

La sauvegarde vit dans le `localStorage` du navigateur (clé `meep-nuit-v1`).
